# bge-m3-korean vs bge-m3-address 임베딩 검색 성능 평가 보고서

## 1. 목적

STT(음성 인식)로 입력된 주소 발화 문장을 임베딩 유사도 검색으로 정답 주소와 매칭시키는 태스크에서, 기본 모델(`bge-m3-korean`)과 STT 주소 데이터로 파인튜닝한 모델(`bge-m3-address`)의 검색 정확도를 비교한다.

## 2. 평가 방법

- **쿼리**: `data/STT발화` — 실제 사람이 발화한 주소를 STT로 인식한 문장 501개 (숫자가 한글로 풀어써지고, 오인식·중복 단어 등 잡음이 포함됨)
- **정답**: `data/STT발화_정답` — 각 발화에 대응하는 정답 주소 501개 (쿼리와 1:1 매칭)
- **후보 풀(gallery)**: 정답 501개 중 중복을 제거한 고유 주소 463개
- **절차**:
  1. 두 모델 각각으로 쿼리 501개, 후보 463개를 임베딩 (mean pooling + L2 normalize)
  2. 쿼리별로 후보 463개와 코사인 유사도를 계산해 유사도 내림차순으로 순위(rank)를 매김
  3. 정답 주소가 몇 위(rank)에 위치하는지로 정확도 측정

- **지표**
  - **Recall@K**: 정답이 상위 K위 안에 드는 비율
  - **MRR**(Mean Reciprocal Rank): 정답 순위의 역수(1/rank)를 평균한 값. 1에 가까울수록 항상 1위로 맞춘다는 뜻
  - **평균 순위**: 정답이 평균적으로 몇 위에 위치하는지

## 3. 종합 결과

| 모델 | Recall@1 | Recall@5 | Recall@10 | MRR | 평균 순위 |
|---|---|---|---|---|---|
| bge-m3-korean (기본) | 77.64% | 91.22% | 93.21% | 0.8415 | 4.69 |
| bge-m3-address (파인튜닝) | **84.83%** | **95.21%** | **96.61%** | **0.8916** | **3.24** |

파인튜닝 모델이 모든 지표에서 기본 모델을 앞선다. 특히 1위로 바로 맞추는 비율(Recall@1)이 **77.6% → 84.8%로 7.2%p** 상승했고, 평균 순위도 4.69위 → 3.24위로 개선되어 전반적으로 오답이 상위권에 덜 섞이는 경향을 보인다.

## 4. 케이스 분해 (쿼리 501개 기준, Recall@1 기준 정답/오답 분류)

| 구분 | 건수 | 비율 |
|---|---|---|
| 두 모델 모두 1위로 정답 | 369건 | 73.7% |
| 두 모델 모두 오답 | 56건 | 11.2% |
| korean만 정답, address는 오답 | 20건 | 4.0% |
| address만 정답, korean은 오답 | 56건 | 11.2% |

파인튜닝으로 인해 새로 맞춘 케이스(56건)가 새로 틀린 케이스(20건)보다 약 2.8배 많다. (전체 순위 기준 개선 77건 vs 악화 41건 — `data/eval_comparison.csv` 참고)

## 5. 사례 분석

### 5.1 address만 정답인 경우 (56건) — 파인튜닝 효과가 드러나는 유형

STT 잡음이 심한 문장(오탈자, 단어 중복, 엉뚱한 삽입어)에서 기본 모델은 완전히 다른 지역으로 매칭시키는 반면, 파인튜닝 모델은 정확히 잡아낸다.

| 쿼리 | 정답 | korean 예측(순위) |
|---|---|---|
| 도봉구 도봉 도봉구 도봉로 백사십구 길 십 십일 다시 육 사백일호 방학동... | 도봉구 도봉로149길 11-6 | 서울특별시 도봉구 마들로 859-19 (31위) |
| 어 부산구 서동 금샘로 오백오십육번길 사십칠 선경삼차아파트... | 부산광역시 금정구 금강로565번길 54 | 부산광역시 사상구 모라로192번길 50... (120위) |
| 남동구 경인로 오구삼 다시 일 백십 다방 | 인천광역시 남동구 경인로 593-1 (간석동) | 대구광역시 북구 노원로10길 40... (2위) |

→ 기본 모델은 도로명이 부정확하게 발음/전사된 경우 아예 다른 시/구로 튀는 경향이 있고, 파인튜닝 모델은 이런 노이즈에 더 강건하다.

### 5.2 korean만 정답인 경우 (20건) — 파인튜닝 모델의 약점

파인튜닝 모델이 도로명+건물번호까지는 정확히 맞히지만, **콤마 뒤 건물명/동/호 등 상세 정보** 표기 차이로 순위가 밀리는 경우가 다수 관찰된다.

| 쿼리 | 정답 | address 예측(순위) |
|---|---|---|
| 서초구 서울시 서초구 효령로 팔 사 백삼 동 천일 호 | 서울특별시 서초구 효령로 84 (방배동, 대우효령아파트) | 서울특별시 서초구 효령로 84 103동 1001호 (2위) |
| 경기도 고양시 덕양구 통일로 칠오구번길... 대도빌라 십사동 백이호 | 경기도 고양시 덕양구 통일로759번길 28-3 (관산동, 대도빌라) | 경기도 고양시 향기로 185 (2위) |

→ 도로명·번지는 정확히 인식하지만, 같은 도로명에 건물명/동호수 표기만 다른 후보가 여러 개 있을 때 그 안에서 순위가 흔들리는 경우가 있다.

### 5.3 두 모델 모두 오답인 경우 (56건) — 모델 문제가 아닌 STT 인식 오류 가능성

일부는 임베딩 모델의 한계라기보다 **STT 자체의 인식 오류**(도시명/도로명이 발음이 비슷한 다른 단어로 잘못 인식됨)로 보인다.

| 쿼리 | 정답 | 비고 |
|---|---|---|
| 충남 **아산시** 아산시 배방읍 전하로... | 경상남도 **김해시** 전하로 133 | 시/도 자체가 다르게 인식됨 |
| 부산시 서구 **강남로** 구십사번길... | 부산시 서구 **암남로**94번길 61 | "암남로"→"강남로" 오인식(발음 유사) |

→ 이런 케이스는 임베딩 모델을 더 학습시켜도 해결되기 어렵고, STT 엔진 자체의 개선이나 오인식 패턴을 반영한 데이터 증강이 필요하다.

## 6. 결론 및 제언

1. **파인튜닝 효과는 명확함**: 노이즈가 심한 STT 문장에서 정답 지역을 찾는 능력(Recall@1 기준 +7.2%p)이 뚜렷하게 개선되었다.
2. **다음 개선 포인트**: 도로명·번지가 같고 건물명/동·호만 다른 후보들 간의 세밀한 구분(5.2절)을 강화하는 학습 데이터를 보강하면 좋을 것 같다.
3. **모델 밖의 문제**: 시/도·도로명 자체가 잘못 인식된 STT 오류(5.3절)는 임베딩 모델이 아니라 STT 단계에서 다뤄야 할 문제로 분리해서 볼 필요가 있다.
